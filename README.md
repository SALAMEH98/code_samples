Welcome to my GitHub repository of R and advanced data analysis code examples! This repository serves as a curated technical portfolio to showcase a range of projects demonstrating my proficiency in R programming, data manipulation, exploratory data analysis (EDA), statistical analysis, machine learning workflows, and interactive data visualization using industry-standard tools and best practices.

📂 Repository Overview

This repository is organized into thematic folders, each illustrating a distinct class of analytic tasks:

GIS: Geospatial analysis workflows in R

data_visualization: Static and interactive visualizations (e.g., ggplot2, plotly, R-Shiny)

machine_learning: Predictive modeling and evaluation pipelines

shiny_app: Fully reactive R Shiny applications

survey_example: Examples of survey data processing and reporting

text_processing: Natural language processing with R

tidyverse: Tidy data principles and transformations

web_scraping: Data collection pipelines from web sources

writing_samples

Each subfolder contains well-documented R scripts, R Markdown notebooks, and supporting files that you can run, adapt, and explore on your own.

🛠 Technical Highlights

This repository demonstrates:

Advanced R programming techniques including functional programming with the tidyverse.

Reproducible analytical workflows with R Markdown and dynamic report generation.

Data wrangling, visualization, and modeling, from raw data ingestion to modeled insights.

Interactive Shiny application examples showcasing user-driven analytical experiences.

Modular and reusable code structures, designed to support learning and rapid adaptation.

🧠 What You’ll Learn

By exploring this repository, you’ll gain insight into:

📌 Getting Started

To run these examples locally:

Clone this repository to your local machine.

Install the R packages listed in each project’s script.

Open the RStudio project or R Markdown files to explore code, narratives, and outputs.
